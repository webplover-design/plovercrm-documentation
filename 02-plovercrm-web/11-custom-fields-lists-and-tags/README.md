# 11. Custom Fields, Lists, and Tags

Create and manage the workspace tools your team uses to store lead information, organize records, and apply consistent classifications.

## Articles

1. [Manage Custom Fields](01-manage-custom-fields.md)
2. [Review System-Managed Fields](06-review-system-managed-fields.md)
3. [Manage Lists](07-manage-lists.md)
4. [Manage Tags](08-manage-tags.md)

## Recommended order

Review system-managed fields before creating a custom field. Then create a clear field structure, use lists for broad lead groupings, and use tags for flexible classifications that your team can apply consistently.

> **Caution:** Changing or deleting a custom field can affect existing lead values, forms, imports, filters, reports, templates, and automations. Review dependencies before saving a destructive change.
