# Use Navigation and Header Controls

The PloverCRM Web Dashboard combines a left navigation panel with header controls so you can move between CRM areas, check the current workspace, access account tools, and respond to notices without losing context. This guide explains how to use both control areas safely.

The exact icons, button names, and available sections can vary with your PloverCRM plan, permissions, connected services, and current version. If a label differs, use the matching label displayed in your account.

## Before you begin

- Sign in to the **PloverCRM Web Dashboard**.
- Select the workspace or connected website where you intend to work.
- Confirm that your role allows the areas and actions you need.
- Finish or cancel unsaved edits before navigating to another area.
- Use an approved or fictional record when learning the interface.

## Use the left navigation panel

The left navigation panel is the main route to the dashboard, leads, lead details, activities, deals, data sources, automations, settings, team management, and support. Some entries may be hidden when your role, plan, or workspace does not include the related feature.

1. Locate the vertical navigation panel on the left side of the PloverCRM Web Dashboard.
2. Read the label beside each icon, or hover over an icon when the panel is collapsed.
3. Select **Dashboard** to return to the workspace overview.
4. Select **All Leads** to search, filter, review, or manage lead records.
5. Select the relevant feature area, such as **Activities**, **Deals**, **Data Sources**, **Automations**, or **Settings**.
6. Confirm the selected page or heading after navigation finishes.
7. Check the workspace name before viewing or changing records.

### Expand or collapse navigation

1. Select the menu, sidebar, or collapse control near the top of the panel.
2. When expanded, use the visible labels to locate an area.
3. When collapsed, use the icons and tooltips to identify each destination.
4. Expand the panel again when you need to read a longer label or submenu.

Collapsing the panel changes the layout only. It does not change permissions, workspace data, or records.

### Use nested navigation items

1. Select a navigation item with an expand arrow or submenu indicator.
2. Review the available child pages.
3. Select the specific page that matches your task.
4. Confirm the page heading and selected navigation state.
5. Use the parent item to return to the feature overview when available.

If an item is not visible, do not assume it has been removed. Check your role, selected workspace, connection status, and plan notices first.

## Use header controls

The header is the horizontal control area across the top of the dashboard. Depending on your account, it can contain workspace context, search or refresh controls, notifications, help, profile options, and account actions.

1. Read the header from left to right before selecting a control.
2. Identify the current workspace or website indicator.
3. Use the workspace selector when you need to move to another authorized workspace; see [Switch Workspaces or Websites](03-switch-workspaces-or-websites.md).
4. Use the refresh or reload control only after finishing or canceling unsaved work.
5. Open notifications or notices to review pending reminders, connection warnings, license messages, or account updates.
6. Open **Help** or **Support** when you need documentation or assistance.
7. Open your profile menu for account settings, sign-out, or other identity controls.
8. Close a menu or return to the page after completing the header action.

> **Security note:** Confirm the workspace and website shown in the header before opening or editing leads. A familiar page layout does not guarantee that the correct workspace is selected.

## Follow a notice from the header

1. Select the notice, alert, or status indicator.
2. Read the complete message and identify whether it concerns setup, connection, license, permissions, or a pending task.
3. Open the linked action only when it matches the issue you intend to address.
4. Review the destination page and selected workspace.
5. Complete the requested action, or ask an administrator when the action requires elevated access.
6. Return to the original page and confirm whether the notice has cleared or changed status.

Do not dismiss a connection or license notice without understanding its effect. A dismissed message may no longer be visible even though the underlying issue remains.

## What to verify

After using a navigation or header control, confirm:

- The page heading matches the area you intended to open.
- The workspace and connected website are correct.
- Any filters, selected records, or unsaved changes were not unintentionally lost.
- A notice or status changed only after you completed the intended action.
- A sign-out action returned you to the secure sign-in screen.

## Troubleshooting

- If the navigation panel is missing, expand the browser window, close an open menu, or refresh after confirming there are no unsaved changes.
- If a feature is not listed, ask an administrator to check your role, workspace, plan, and connection status.
- If a header menu does not open, select the control once and check whether a browser pop-up or extension is interfering.
- If navigation opens the wrong workspace, stop and use the workspace selector before opening any records.
- If a page is blank or stale, refresh once and check the connection status before repeating the action.

> **Security and privacy:** Never include passwords, one-time codes, API keys, connection tokens, private URLs, payment details, or identifiable customer data in screenshots, exports, notes, or support requests. Use approved support channels and redact diagnostic material before sharing it.
