# Edit Lead Information

You can edit available lead details directly in the Lead Detail Drawer. The edit control appears when you hover over an editable detail.

> **Image:** `[Add screenshot here]`

## Edit a lead detail

1. Open the lead in the **Lead Detail Drawer**.
2. In the **Contact** tab, move the pointer over the detail you want to change.
3. Select the **pencil** icon that appears.
4. Enter the new value in the field.
5. Select the **checkmark** to save the change, or select the **X** to cancel it.
6. Repeat these steps for any other editable details.

In the example shown, the email address and phone number are being edited. The change is saved separately for each field.

## Read-only details

Some details do not show a pencil icon or cannot be edited. These fields are read-only because they are controlled by PloverCRM, the lead source, or your account permissions. You cannot change them from the drawer.

If an edit control is unavailable, do not try to change the field through another unrelated control. Contact a workspace administrator if you believe you should have permission to edit it.

## Cancel an edit

To discard a change before saving, select the **X** beside the field. The original value remains unchanged.
