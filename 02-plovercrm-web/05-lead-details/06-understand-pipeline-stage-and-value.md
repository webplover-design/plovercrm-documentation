# Understand Pipeline Stage and Value

The **Pipeline** card in the Lead Detail Drawer shows where a lead is in your sales process and the value associated with the lead.

> **Image:** `[Add screenshot here]`

## View the current stage

1. Open a lead from the **Leads** table.
2. In the Lead Detail Drawer, locate the **Pipeline** card.
3. Review the **Current stage** label and the highlighted point on the stage indicator.

The available stages are configured for the workspace. The stage names and number of stages may differ between workspaces.

## View the lead value

The **Value** field in the Pipeline card shows the monetary value recorded for the lead. If no value has been entered, the value may appear as `$0`.

The displayed currency and formatting depend on the workspace configuration.

## Change the stage or value

If your role allows editing, use the available stage selector or editable value control in the lead drawer. Choose the new stage or enter the new value, then save the change when prompted.

If the control is unavailable or read-only, you do not have permission to change that field. Contact a workspace administrator if you need access.
