# View Custom Fields and Lead Metadata

The Lead Detail Drawer can show information captured in custom fields and other lead metadata. Custom fields allow a workspace to store information that is specific to its business or lead-capture process.

> **Image:** `[Add screenshot here]`

## View custom fields

1. Open a lead from the **Leads** table.
2. In the Lead Detail Drawer, locate the **Custom Fields** card.
3. Review the field names and values shown for the lead.
4. Scroll within the drawer to view additional fields when necessary.

A field may show no value when the lead did not provide information for it or the value has not been entered.

## Understand metadata

Lead metadata is supporting information stored with the lead, such as values captured from a form, source-specific details, or other workspace-defined information. The fields shown depend on the workspace configuration and the data available for that lead.

Custom fields and metadata are separate from the standard contact details shown in the Identity Info card.

## Edit a custom-field value

If a custom field is editable, hover over its value and select the pencil icon. Enter the new value and select the checkmark to save it, or select **X** to cancel.

If no edit control appears, the field is read-only or your role does not allow changes.
