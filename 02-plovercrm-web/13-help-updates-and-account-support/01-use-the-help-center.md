# Use the Help Center

The PloverCRM Help Center provides instructions for setting up workspaces, managing leads, configuring features, and resolving common problems. Use it before contacting support so you can find the relevant workflow and provide more useful details if assistance is still needed.

> **Image:** `[Add screenshot here]`

## Open the Help Center

1. Sign in to the PloverCRM Web Dashboard.
2. Open the **Help**, **Support**, or account menu shown in the navigation or header.
3. Select **Help Center** or the matching option.
4. Search for the task, feature, or error you need help with.
5. Open the closest article and confirm that it applies to your PloverCRM version, workspace, and permissions.
6. Follow the steps in order and complete only the steps relevant to your issue.

The location and label may vary by version, plan, and account access.

## Search effectively

Search with the task and feature name rather than a general description. Useful searches include:

- `connect WordPress website`
- `import leads from CSV`
- `create reminder`
- `workspace permissions`
- `browser notifications`
- `automation failed`

If the first result does not match your screen, shorten the search phrase, try a synonym, or browse the relevant category. Compare the article’s screenshots and terminology with your account before changing settings.

## Use an article safely

1. Confirm the workspace or website selected in PloverCRM.
2. Check whether the article requires an administrator role.
3. Review warnings before changing records, permissions, integrations, or automations.
4. Use test data when the workflow can send messages, create records, or trigger an external service.
5. Save or apply one change at a time.
6. Verify the result before continuing to another change.

Do not follow an instruction for a different product, environment, or workspace simply because the feature name is similar.

## Before contacting support

Record the feature, screen, steps you followed, exact non-sensitive error text, approximate time, and whether the issue affects one user or several. Keep passwords, tokens, private URLs, and customer information out of searches, screenshots, and notes.

If the Help Center does not resolve the problem, use [Contact Support](02-contact-support.md).
