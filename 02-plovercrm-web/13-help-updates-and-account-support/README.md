## Which article should I read?

- Start with [Use the Help Center](01-use-the-help-center.md) when you need setup guidance or instructions.
- Use [Contact Support](02-contact-support.md) when the Help Center does not resolve the issue.
- Read [View What's New](03-view-whats-new.md) for recent product updates.
- Use [Request a Feature](04-request-a-feature.md) to suggest an improvement.
- Read [Understand the Advocate Program](05-understand-the-advocate-program.md) before participating in advocacy activities.
- Read [Understand License and Plan Notices](06-understand-license-and-plan-notices.md) when a plan, license, connection, or feature-availability notice appears.

> **Security note:** Never include passwords, tokens, private URLs, payment information, or identifiable customer data in screenshots or support requests. Redact diagnostic material before sharing it.
