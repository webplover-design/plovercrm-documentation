# 6. Activities and Reminders

Record work performed for a lead and create reminders so follow-up tasks remain visible and organized.

## Articles

1. [Manage Lead Activities](01-manage-lead-activities.md)
2. [Create and Manage Lead Reminders](02-create-and-manage-lead-reminders.md)
3. [Use Global Reminders and Browser Notifications](03-use-global-reminders-and-notifications.md)

## Recommended order

Start with the activity timeline when reviewing work on one lead. Create reminders for future follow-up, then use the global Reminders page to manage reminders across leads.

> **Privacy note:** Do not record passwords, payment details, or unnecessary sensitive customer information in activities, notes, or reminders.
