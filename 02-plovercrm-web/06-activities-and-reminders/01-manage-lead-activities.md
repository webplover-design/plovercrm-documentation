# Manage Lead Activities

Review a lead's activity timeline, filter activity history, add manual activities or notes, and edit or delete entries from the Lead Detail Drawer.

> **Image:** `[Add screenshot here]`

## Review the activity timeline

1. Open the lead in the **Lead Detail Drawer**.
2. Select the **Activity** tab.
3. Review the activity timeline from newest to oldest.
4. Select an activity when you need to view its details.

The timeline can include activities recorded by PloverCRM and activities added manually by teammates.

## Filter activity history

Use the available activity filters to narrow the timeline to the entries you need. Filters may include activity type, date, or other available criteria.

Clear the filters to return to the complete activity history.

## Add a manual activity or note

1. Open the lead's activity timeline.
2. Select **Add Activity**.
3. Choose the activity type or note option shown.
4. Enter the relevant details.
5. Review the lead association and any date or time fields.
6. Save the activity.

Write clear, work-related notes. Do not store passwords, payment details, or unnecessary sensitive information in an activity.

## Edit or delete an activity

Open the activity's action menu and select **Edit** or **Delete**, when available. Review changes before saving an edit. For deletion, read the confirmation and confirm only when you are sure the activity should be removed.
