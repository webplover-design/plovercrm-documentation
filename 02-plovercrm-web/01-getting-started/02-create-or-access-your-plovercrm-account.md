# Create or Access Your PloverCRM Account

Create a PloverCRM account for a new setup, or sign in if your account already exists.

![Placeholder screenshot of the PloverCRM account sign-in screen](images/placeholder-account-sign-in.png)

## Choose the right path

- Choose **Create an account** if you are starting a new PloverCRM setup.
- Choose **Log in** if your PloverCRM account already exists.
- If a teammate invited you, accept the invitation using the email address that received it, then sign in with your own account.
- If you are unsure which workspace to use, ask a workspace administrator before changing setup or website settings.

## Before you start

- Use an email address you can access.
- If you are connecting a WordPress website, make sure you can install plugins or ask a WordPress administrator to help.
- Do not use a shared password for your PloverCRM account.

## Create an account

1. Open the PloverCRM website.
2. Choose the option to start a trial or create an account.
3. Enter the requested account details.
4. Complete any verification step shown by PloverCRM.
5. Sign in with the account you created.

![Placeholder screenshot of the PloverCRM account creation form](images/placeholder-account-creation.png)

> **Screenshot placeholder:** Replace this image with an approved PloverCRM account-creation screenshot after the workflow and privacy review are complete.

After you sign in, PloverCRM opens the setup flow or your available workspace. Continue with [Download, Install, and Connect the PloverCRM Plugin](03-download-the-plovercrm-plugin.md) when you are setting up a WordPress website.

## Access an existing account

1. Open the PloverCRM website.
2. Choose **Log in** or the sign-in option.
3. Enter your PloverCRM account email or username and password.
4. Submit the form.
5. If prompted, select the workspace or website you want to manage.

If you cannot sign in, see [Log In to the PloverCRM Web Dashboard](06-log-in-to-plovercrm-web.md) and the web troubleshooting guides.

## Security reminder

Enter credentials only in the PloverCRM sign-in screen. Never send your password or one-time verification codes through support requests, screenshots, or chat.
