# Complete Guided Workspace Setup

Complete the guided setup after the PloverCRM plugin is connected and activated. The setup prepares the workspace for lead capture and daily CRM work.

## Before you start

- Create or access your PloverCRM account.
- Install, connect, and activate the PloverCRM plugin on the intended WordPress website.
- Have permission to configure the workspace and website connection.
- Have the information your team uses for lead routing, lists, tags, and pipeline stages.

If you have not connected the plugin yet, follow [Download, Install, and Connect the PloverCRM Plugin](03-download-the-plovercrm-plugin.md).

## Complete the setup flow

1. Sign in to PloverCRM.
2. Select the website or workspace connected to your WordPress site.
3. Open the guided setup when PloverCRM displays the setup prompt.
4. Review the website and workspace details.
5. Confirm the workspace name and other basic information requested by PloverCRM.
6. Configure the lead capture settings for the forms or sources you plan to use.
7. Review or create pipeline stages for your team's process.
8. Choose the default lists, tags, or routing options shown in the setup flow.
9. Save each setup step.
10. Review the final summary and finish setup.

The available steps depend on your workspace and enabled features. Follow the labels displayed in your current PloverCRM screen.

## Verify the workspace

After the guided setup finishes:

1. Open the PloverCRM Web Dashboard from the connected website's dashboard or the PloverCRM sign-in page.
2. Confirm that the intended website or workspace is selected.
3. Check that the connection status shows the workspace as available or connected.
4. Review the configured pipeline stages and lead-capture settings.
5. Submit a test lead only when your team has approved a test and the source is ready.
6. Confirm that the lead appears in PloverCRM with the expected list, tag, stage, or assignment.

Do not use real customer information for a test submission. Remove test data when your team's process requires it.

## Configure data capture and pipeline settings

Continue with [Configure Data Capture and Pipeline Setup](05-configure-data-capture-and-pipeline-setup.md) to review the settings in more detail.

## Open PloverCRM after activation

Once the plugin is activated, PloverCRM appears on the connected website's dashboard. Open the PloverCRM Web Dashboard directly from that dashboard, or sign in through the PloverCRM sign-in page and select the workspace.

There is no separate setup step for opening the app. If PloverCRM is not visible, confirm that the plugin is active and that you are viewing the correct WordPress dashboard or workspace.

## If setup is interrupted

- Return to the PloverCRM dashboard and look for the setup prompt or workspace settings.
- Confirm that the plugin connection is still active.
- Select the correct website or workspace before continuing.
- Save completed steps before leaving the setup flow.
- Ask a workspace administrator to continue setup if your role does not include configuration access.
- For connection problems, see [Troubleshoot Plugin Connection and Activation](../14-web-troubleshooting/03-troubleshoot-plugin-connection-and-activation.md).
