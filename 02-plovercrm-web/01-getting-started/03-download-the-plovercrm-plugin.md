# Download, Install, and Connect the PloverCRM Plugin

Use the setup flow to download the PloverCRM plugin, install it on WordPress, connect your website, and activate the connection. These steps are part of one onboarding workflow.

## Before you start

- Create or access your PloverCRM account.
- Have administrator access to the WordPress website you want to connect.
- Keep the PloverCRM setup screen open while you move between PloverCRM and WordPress.
- Do not share your PloverCRM password or private website details in screenshots or support requests.

## Download the plugin

1. Sign in to PloverCRM.
2. Start the website or workspace setup flow.
3. Choose the option to download the PloverCRM plugin.
4. Save the plugin package to your computer.
5. Return to the setup flow and continue to the WordPress installation step.

PloverCRM provides the plugin download during account or website setup. Use the package supplied by PloverCRM rather than an unknown copy.

## Install the plugin on WordPress

1. Sign in to the WordPress administration area for the website.
2. Open **Plugins** and choose **Add New Plugin**.
3. Choose **Upload Plugin**.
4. Select the PloverCRM plugin package you downloaded.
5. Choose **Install Now**.
6. When installation finishes, choose **Activate Plugin**.

If WordPress reports an installation error, confirm that you used the complete plugin package and that your WordPress account can install plugins. Do not upload credentials or private site data when requesting help.

## Add the website in PloverCRM

1. Return to PloverCRM.
2. In the website or workspace setup step, choose **Add Website**, **Add Site**, or the equivalent option shown in your account.
3. Enter the website address requested by PloverCRM.
4. Save the website entry.
5. Select the website you just added to continue setup.

If PloverCRM offers an import option for an existing website entry, choose **Import** and follow the displayed instructions instead of creating a second entry.

## Connect and activate the plugin

1. Open the PloverCRM connection step for the website.
2. Copy or note the connection details shown by PloverCRM.
3. In WordPress, open the PloverCRM plugin settings.
4. Enter the requested connection details in the plugin screen.
5. Save the plugin settings.
6. Return to PloverCRM and choose **Test Connection** or **Connect**.
7. Wait for the connection check to finish.
8. Choose **Activate** or **Activate Plugin** when PloverCRM reports a successful connection.

The exact labels may vary by version. Use the labels shown in your current PloverCRM and WordPress screens.

> **Security note:** Enter credentials only in the PloverCRM sign-in or credential screen. Do not include passwords, tokens, private URLs, or customer data in screenshots or support requests.

## What happens next

After activation, PloverCRM associates the WordPress website with your workspace. PloverCRM then makes the CRM available from the connected website's dashboard and continues to the guided workspace setup.

Continue with [Complete Guided Workspace Setup](04-complete-guided-workspace-setup.md), then configure [data capture and pipeline setup](05-configure-data-capture-and-pipeline-setup.md).

## If the connection does not activate

- Confirm that the plugin is installed and active in WordPress.
- Confirm that the website address is entered correctly in PloverCRM.
- Check that your WordPress account has permission to change plugin settings.
- Run the connection test again from the PloverCRM setup flow.
- Ask a WordPress administrator to check the plugin settings.
- If the test still fails, see [Troubleshoot Plugin Connection and Activation](../14-web-troubleshooting/03-troubleshoot-plugin-connection-and-activation.md).
