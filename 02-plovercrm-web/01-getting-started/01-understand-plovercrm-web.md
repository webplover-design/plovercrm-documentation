# Understand the PloverCRM Web Dashboard

## What you can do

PloverCRM Web helps you:

- Capture leads from your connected website and other configured sources.
- Review, search, filter, and organize leads.
- Assign leads, update pipeline stages, and record activities.
- Create reminders and follow up with leads.
- Configure lists, tags, custom fields, notifications, and workspace settings.
- Connect additional data sources and automate routine work when those features are available in your workspace.

## How the pieces fit together

![Placeholder screenshot of the PloverCRM Web workspace selector](images/placeholder-web-workspace-selector.png)

> **Screenshot placeholder:** Replace this image with an approved workspace or website selector screenshot after the workflow and privacy review are complete.

1. Your PloverCRM account provides access to the PloverCRM Web Dashboard.
2. The PloverCRM plugin connects an authorized WordPress website to a workspace.
3. The workspace stores the leads and settings used by your team.
4. PloverCRM Web provides the screens used to manage that workspace.

A workspace is associated with a connected website. If you manage more than one website, use the workspace or website switcher to choose the data you want to view before making changes.

## Keep access secure

Use your own PloverCRM account and the permissions assigned to you. Do not share passwords, tokens, or private customer information in screenshots, support requests, or documentation.
