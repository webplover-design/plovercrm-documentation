Set up the PloverCRM plugin, connect a WordPress website, prepare the workspace, and sign in to PloverCRM Web.

## Onboarding in one flow

The onboarding path is intentionally covered by the setup articles above:

1. Create or access the PloverCRM account.
2. Download the plugin from PloverCRM.
3. Install and activate the plugin on WordPress.
4. Add or import the website in PloverCRM.
5. Connect the website and activate the plugin connection.
6. Complete the guided workspace setup.
7. Configure data capture and pipeline stages.
8. Open the PloverCRM Web Dashboard from the connected website dashboard or sign in to it.

The PloverCRM plugin appears on the connected website's dashboard after activation, so opening the PloverCRM Web Dashboard is included in [Complete Guided Workspace Setup](04-complete-guided-workspace-setup.md) rather than maintained as a separate article.
