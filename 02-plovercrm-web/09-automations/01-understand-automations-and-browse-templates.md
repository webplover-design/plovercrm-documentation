# Understand Automations and Browse Templates

An automation is a workflow that starts when a selected event occurs and then performs one or more actions. For example, an automation can respond to a new lead, update lead information, send an internal email, or send a conversion event to a connected advertising service.

## Understand the parts of an automation

- **Trigger:** The event that starts the workflow.
- **Conditions:** Rules that determine which leads or events can enter the workflow.
- **Actions:** The work PloverCRM performs after the trigger matches.
- **Status:** Whether the automation is enabled, disabled, or otherwise available to run.
- **Queue and logs:** The processing and history information used to monitor runs.

An enabled automation can act automatically on future events. Review every trigger and action before enabling it.

## Browse templates

1. Open **Automations** from the main navigation.
2. Open the template or flow-template area.
3. Browse the available templates.
4. Select a template to review its purpose, trigger, conditions, and actions.
5. Choose a template that matches the workflow you want to automate.

Templates provide a starting configuration. They do not replace reviewing the trigger, recipient, lead scope, external connection, or message content.

## Choose between a template and a blank automation

Use a template when the available workflow is close to what you need and you want to adjust it. Start from scratch when you need a different trigger, action sequence, or set of conditions.

Before choosing, check whether the template requires an external connection such as Google Ads or Meta CAPI.

## Before enabling an automation

Confirm the leads that can enter it, the actions it will perform, the timing, the people or services that will receive information, and whether any action is irreversible. Test with approved data whenever the feature provides a test or preview option.
