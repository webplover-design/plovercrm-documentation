## Recommended order

Start by understanding the automation and reviewing templates. Create the workflow, configure its trigger and actions, connect any required providers, and test the result before enabling it. Use logs and queue status to monitor the first runs.

> **Caution:** An enabled automation can act automatically on future leads. Review the scope, timing, recipients, message content, and external actions before activation.
