# Create and Configure an Automation

Create an automation from a template or start with a blank workflow. Then give it a clear identity and configure its basic settings before adding detailed triggers and actions.

> **Image:** `[Add screenshot here]`

## Create from a template

1. Open **Automations**.
2. Open the flow-template area.
3. Select a template and review its trigger and actions.
4. Select **Use template** or the matching button.
5. Enter a clear automation name.
6. Review the copied settings and save the automation.

## Create from scratch

1. Open **Automations**.
2. Select **Create automation** or the matching button.
3. Choose the blank or from-scratch option.
4. Enter a clear name and description.
5. Save the new automation.
6. Continue to configure its trigger and actions.

## Configure the basic settings

Review the automation name, description, status, workspace or lead scope, and any other settings shown on the configuration screen. Use a name that explains both the event and the result, such as “Notify sales team when a qualified lead arrives.”

Do not enable the automation yet if its trigger, conditions, actions, recipients, or external connections are not complete.

## Save and continue

Save after the basic settings are complete. Then open the trigger and action configuration. If PloverCRM shows validation messages, correct required fields before continuing.
