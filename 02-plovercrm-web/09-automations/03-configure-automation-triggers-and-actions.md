# Configure Automation Triggers and Actions

The trigger decides when an automation starts. Actions decide what it does after a matching event occurs.

> **Image:** `[Add screenshot here]`

## Configure the trigger

1. Open the automation.
2. Open **Triggers** or the matching configuration section.
3. Choose the event that should start the automation.
4. Add conditions that limit which leads or events qualify.
5. Review the trigger summary and save it.

Choose conditions carefully. A broad trigger can enter more leads than expected, while an overly narrow trigger may never run.

## Add actions

1. Open **Actions**.
2. Select **Add action**.
3. Choose the action type.
4. Complete the required settings.
5. Arrange actions in the order they should run.
6. Save the action and repeat for each required step.

Review recipients, message content, field changes, delays, and external conversion actions. Some actions require a connected provider.

## Review before enabling

Read the complete trigger and action sequence from beginning to end. Confirm the lead scope, conditions, order, timing, recipients, and external services. Use preview or test controls when available, then save the workflow.
