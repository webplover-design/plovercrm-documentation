## Start here

Choose the guide that matches the screen or action where the problem occurred. Confirm the selected workspace before changing settings, retrying an import, or asking another teammate to test the issue.

## Before contacting support

Record the non-sensitive error message, the affected feature, the steps that led to the problem, and whether another authorized user can reproduce it. Remove passwords, tokens, private URLs, and customer information from screenshots and support requests.
