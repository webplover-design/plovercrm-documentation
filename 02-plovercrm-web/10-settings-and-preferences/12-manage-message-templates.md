# Manage Message Templates

Message templates provide reusable email or message content. A template can save time, but it should still be reviewed before sending because placeholders and lead information may change.

> **Image:** `[Add screenshot here]`

## Create a template

1. Open **Settings** and select **Message Templates**.
2. Select **Create template** or the matching action.
3. Enter a descriptive name and choose the message type when prompted.
4. Write the subject and body.
5. Insert only supported placeholders from the template editor.
6. Save the template.

## Edit and test a template

1. Open the template and review its current content.
2. Update the wording, recipients, or placeholders as needed.
3. Use preview or send a test to an approved internal address when available.
4. Check that placeholders resolve correctly and that the message is appropriate for the intended audience.
5. Save the final version.

Do not include passwords, tokens, or unnecessary personal information. Editing a shared template may affect other users and automated messages.

## Disable or remove a template

Use the available archive, disable, or delete action only after checking automations and workflows that reference the template. Keep a replacement ready when the template is used operationally.
