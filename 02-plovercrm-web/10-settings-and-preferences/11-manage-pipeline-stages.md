# Manage Pipeline Stages

Pipeline stages describe where leads or deals are in your sales process. Stage names and order are shared workflow settings, so agree on changes with the team before applying them.

> **Image:** `[Add screenshot here]`

## Review existing stages

1. Open **Settings**.
2. Select **Stages** or the pipeline settings page.
3. Review the stage names, order, status, and any associated configuration.
4. Identify which existing records and automations may depend on a stage before changing it.

## Add or edit a stage

1. Select **Add stage** or open an existing stage for editing.
2. Enter a clear name that describes one step in the process.
3. Complete any required status, color, or position settings.
4. Place the stage in the correct order.
5. Save the change.
6. Open the pipeline and verify the stage appears as expected.

## Reorder, disable, or remove a stage

Use the available reorder, disable, archive, or delete control. Read the warning first. If records, automations, reports, or deals use the stage, choose the safest supported option and map affected records when prompted.

Changing a stage changes the record’s position; it does not automatically create a new deal or change the deal value. Test automations that use the stage after saving.
