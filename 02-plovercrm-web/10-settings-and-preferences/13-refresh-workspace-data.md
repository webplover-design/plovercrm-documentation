# Refresh Workspace Data

Use the workspace refresh option when the application provides one and displayed settings or records appear out of date. Refreshing reloads data; it does not replace a missing connection or undo a saved change.

> **Image:** `[Add screenshot here]`

## Refresh the workspace

1. Open **Settings** and select the workspace or data-refresh area.
2. Confirm that the intended workspace is selected.
3. Check whether another refresh or synchronization is already running.
4. Select **Refresh**, **Sync**, or the matching action once.
5. Wait for the completion message or status update.
6. Reload the affected page and check the result.

Do not repeatedly click refresh while processing is in progress. If the operation is asynchronous, use its status instead of starting another request.

## If data remains stale

Clear filters, confirm the workspace, check the connected source status, and refresh the page once. Review logs when the feature provides them. If records are missing, do not recreate or reimport them until you confirm whether synchronization is still pending.
