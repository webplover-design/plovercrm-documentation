# Configure Browser Notifications

Browser notifications allow PloverCRM to show alerts outside the active page when the browser and operating system permit them. They depend on both PloverCRM preferences and browser permission.

> **Image:** `[Add screenshot here]`

## Enable notifications in PloverCRM

1. Open **Settings** and select **Notifications**.
2. Enable the browser-notification option or the event types you want.
3. Save the setting if required.
4. When the browser asks for permission, select **Allow**.

## Check browser permission

If no prompt appears, open the browser’s site permissions for PloverCRM and set notifications to **Allow**. Confirm that the operating system is not blocking notifications or using a focus mode.

## Test and disable notifications

Trigger or wait for an approved test alert. If it appears, verify that it contains no unnecessary private information. To stop browser alerts, disable the PloverCRM option or change the browser permission to **Block**.

Browser permission does not replace PloverCRM alert preferences; both must allow the notification.
