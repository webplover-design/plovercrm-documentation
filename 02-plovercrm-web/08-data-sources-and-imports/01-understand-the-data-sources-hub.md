# Understand the Data Sources Hub

The **Data Sources** area is where you connect services that send leads to PloverCRM, configure webhooks and routing, import CSV files, and review connection status.

> **Image:** `[Add screenshot here]`

## What you can do

Depending on your permissions and connected services, the hub may let you:

- Connect website forms and third-party lead sources.
- Connect Google Ads and Meta lead forms.
- Create and manage webhooks.
- Import leads from CSV files.
- Configure lists, tags, assignment, stages, and other routing defaults.
- Review source status and logs.
- Repair or disconnect a source.

## Open Data Sources

1. Select **Data Sources** from the main navigation.
2. Review the connected sources and their current status.
3. Select a source to view its settings, logs, or available actions.
4. Select the option to add a source when you need a new connection.

The controls shown depend on the source type and your permissions.

## Before connecting a source

Know which workspace should receive the leads, which fields are required, and which teammate or process should handle new submissions. Use a test submission when the source supports testing.
