# Connect a Form Data Source

Connect a supported website or form provider so new form submissions can be received as leads in PloverCRM.

> **Image:** `[Add screenshot here]`

## Connect the source

1. Open **Data Sources**.
2. Select **Add Source** or the matching button.
3. Choose the form or website source.
4. Enter the requested source details or complete the provider authorization.
5. Save the connection.

## Configure the source

Review the destination workspace, field mapping, default stage, assignment, lists, tags, and any available duplicate settings. Configure only the options required for this source.

## Test the connection

Send an approved test submission through the form when possible. Check the source log and open the resulting lead to confirm that the expected values and routing were applied.

## Troubleshooting

If the source does not connect, check the authorization, source URL, required fields, and provider permissions. If the connection succeeds but leads do not arrive, review the source logs and submit a new test event.
