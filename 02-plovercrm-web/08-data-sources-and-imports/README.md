## Before you begin

Confirm the destination workspace and the fields your team needs before connecting a source or importing records. Use a small approved test or a copy of the data when validating a new mapping.

> **Caution:** Imports and routing changes can create or update many leads. Review field mappings, lists, tags, delimiter, header settings, and duplicate behavior before starting.
