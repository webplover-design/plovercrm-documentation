# Resume a Historical Import

Use the resume option when a historical CSV import was interrupted or left incomplete and PloverCRM provides a resumable import record.

> **Image:** `[Add screenshot here]`

## Resume an available import

1. Open **Data Sources**.
2. Open the import or historical-import area.
3. Select the incomplete import.
4. Review its file, row count, mapping, and current status.
5. Select **Resume** or the matching action.
6. Review the remaining rows and start the process.
7. Wait for completion before starting another import from the same file.

Do not resume an import if the file or mapping has changed unless PloverCRM specifically asks you to upload or remap it.

## If resume is unavailable

The import may have completed, expired, failed permanently, or not support resuming. Review the available status and use the failed-row workflow or start a new import with a corrected file when appropriate.
