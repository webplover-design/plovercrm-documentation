# Manage Message Templates

Create and manage reusable message templates for email and SMS communication from lead details.

## Open Message Templates

1. Open PloverCRM.
2. Tap **Settings**.
3. Under **App preferences**, tap **Lead Details**.
4. Under **Message Templates**, tap **Manage Templates**.

## Find a template

Enter text in **Search templates** to search template titles and message content. Clear the search field to return to the full list.

## Create a template

1. Open **Message Templates**.
2. Tap **New**.
3. Enter the template title and message content.
4. Save the template using the controls shown by PloverCRM.

The new template appears in the template list after it is saved.

## Edit or view a template

1. Tap the edit control for a template.
2. Update the title or message content when you have edit permission.
3. Save the changes.

If you can view but not edit templates, the control is shown as a view option instead.

## Reorder templates

1. Clear the search field.
2. Use the up or down controls beside a template.
3. Repeat until the templates are in the order you want.

Templates cannot be reordered while a search is active. PloverCRM can show **Clear search to reorder templates**.

## Use a template from a lead

When a template is opened with lead information available:

1. Review the rendered message preview.
2. Tap **Use Template**.
3. Review the message before sending it.

## Delete a template

1. Tap the delete control for the template.
2. Review the confirmation dialog.
3. Tap **Delete** only when you are certain.

> **Warning:** Deleting a template removes it from the workspace template list. Confirm that you no longer need it before choosing **Delete**.

## Permissions and troubleshooting

### Templates are unavailable

Your role may not have access to message templates. Ask your workspace administrator to review your permissions.

### The New button is missing

You may have view-only access. Only teammates with template-management permission can create, edit, reorder, or delete shared templates.

### No template matches the search

Try a shorter search term or clear the search field to view all templates.
