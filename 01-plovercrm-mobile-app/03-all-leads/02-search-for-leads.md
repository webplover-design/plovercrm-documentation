# Search for Leads and Understand Search Results

Use the Search control on **All Leads** to find leads by a text query or filters. PloverCRM shows the result count and the conditions used to produce the results, so you can tell whether you are viewing the full workspace or a filtered set of leads.

## Before you start

- Open **All Leads** in the PloverCRM mobile app.
- Know the name, email address, phone number, or other information you want to search for.

## Search for a lead

1. Open **All Leads**.
2. Tap the search icon in the top area of the screen.
3. In **Search leads...**, enter a search term.
4. Tap **Search** or submit the search from the keyboard.
5. Review the matching results.

The search can be used with a text query, filters, or both. A text query is not required when you use filters only.

## Search selected fields

1. Open the Search panel.
2. Turn on **Advanced Search**.
3. Tap **Search fields**.
4. Select the fields that should be searched.
5. Use **Find a field...** to locate a field quickly.
6. Tap **Apply**.
7. Enter your search term and tap **Search**.

If no specific fields are selected, PloverCRM uses the default searchable fields.

## Read the results summary

When a search or filter is active, the results area shows:

- The number of matching results.
- The text query, when one was entered.
- Selected search fields.
- Selected lists, tags, or pipeline stages.
- The selected created or updated date range.
- **Clear all**, which removes the active search and filters.

## Remove one active filter

1. Find the filter chip above the lead table.
2. Tap the close icon on the filter you want to remove.
3. Review the updated result count.

Removing the last active filter returns the lead list to its normal workspace view.

## Clear all active filters

1. Tap **Clear all** in the active-filters area.
2. Wait for the full lead list to reload.

The search text, selected fields, lists, tags, stages, and date range are cleared together.

You can also open the Search panel and tap **Clear** to remove the current search and filters.

## Understand visible results and total results

PloverCRM loads the lead list in pages. The number of rows currently visible on the screen may be smaller than the total result count.

Scroll toward the end of the list to load more matching leads. The search or filter remains active while additional results are loaded.

## Understand query scope for bulk selection

When you select every visible lead, the bulk-selection bar can offer an option such as **Select all [number] leads matching this filter**.

- Selecting the visible leads applies the selection only to the rows currently loaded.
- Selecting the query scope includes all leads that match the current search or filter, including results on other pages.
- Review the selection count before applying a bulk action.

Use query-scope selection carefully, especially before changing or deleting leads.

## What happens next

PloverCRM displays the matching results in **All Leads**. Review the result count and active filters before opening a lead or applying a bulk action.
