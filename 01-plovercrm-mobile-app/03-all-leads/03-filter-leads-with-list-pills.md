# Filter Leads with List Pills

List pills provide a quick way to filter the **All Leads** screen by one or more workspace lists.

## Before you start

- Open **All Leads**.
- Make sure the active workspace contains at least one available list.

## Apply a list filter

1. Find the list-pill bar at the bottom of the All Leads screen.
2. Swipe the bar horizontally if the list you need is not visible.
3. Tap a list pill.
4. Wait for the lead list to update.

The selected list changes to an active state, and the lead table shows leads assigned to that list.

## Apply more than one list filter

Tap additional list pills to include more than one list in the active filter. The selected lists appear together in the active filter state.

Review the result count and active filter chips above the table after selecting multiple lists.

## Remove a list filter

1. Find the selected list pill.
2. Tap its close icon.
3. Wait for the lead list to update.

If no list filters remain, PloverCRM returns to the previous search or full-list view.

You can also remove a list from the active-filters area above the table.

## Understand unavailable lists

Some system lists are not shown in the list-pill bar. If a list is missing, use the Search panel or the workspace list-management area to review the lists available to your account.
