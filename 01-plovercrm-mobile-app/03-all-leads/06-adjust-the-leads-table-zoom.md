# Adjust the Leads Table Zoom

Change the size of the lead table when you need to see more columns at once or make table content easier to read.

## Open the table zoom control

1. Open **All Leads**.
2. Tap the table-zoom control near the top of the screen.
3. Review the available zoom percentages.

![Placeholder image of the PloverCRM Leads Table Zoom control](images/placeholder-mobile-leads-table-zoom.png)

> **Image placeholder:** Replace this image path with the final table-zoom screenshot when it is available.

## Choose a zoom level

Choose one of the available preset percentages:

- **20%**
- **50%**
- **75%**
- **100%**
- **125%**
- **150%**
- **160%**

You can also use the minus and plus controls to adjust the current percentage in smaller steps.

## Understand what zoom changes

Changing the zoom changes the size of the table text, cells, and columns. It does not change the number of leads in the workspace or alter your lead data.

Swipe horizontally across the table when additional columns remain outside the visible area.

## What happens next

PloverCRM keeps the selected table zoom for the mobile app. You can return to the zoom control at any time to choose another percentage.
