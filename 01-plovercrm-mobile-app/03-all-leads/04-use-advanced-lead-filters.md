# Use Advanced Lead Filters

Use **Advanced Search** to filter leads by fields, lists, tags, pipeline stages, and created or updated dates. You can combine several filters in one search.

## Open Advanced Search

1. Open **All Leads**.
2. Tap the search icon.
3. Turn on **Advanced Search**.

## Select fields to search

1. Tap **Search fields**.
2. Use **Find a field...** to locate a field.
3. Select the fields you want to search.
4. Use **Select all** or **Clear** when appropriate.
5. Tap **Apply**.

PloverCRM groups available fields and can include standard lead fields, custom fields, and **Lead ID**.

## Filter by lists, tags, or stages

1. In Advanced Search, tap **Lists**, **Tags**, or **Stages**.
2. Search within the selection dialog if needed.
3. Select one or more values.
4. Tap **Done**.

Selected values are shown on the filter control and in the active-filters area after the search is applied.

## Filter by date

1. In Advanced Search, choose **Created** or **Updated**.
2. Select a preset such as **Today**, **Yesterday**, **Last 7 days**, **Last 30 days**, or **This month**.
3. To specify a custom range, choose a **From** date and a **To** date.
4. Enter a text query if needed.
5. Tap **Search**.

You can use date filters without entering search text.

![Placeholder image of PloverCRM date filters](images/placeholder-mobile-date-filters.png)

## Apply the filters

1. Review the selected fields and filter values.
2. Tap **Search**.
3. Review the result count and active filter chips above the lead table.

## Clear advanced filters

- Tap **Clear** in the Search panel to remove all search text and filters.
- Tap the close icon on an individual active filter to remove only that filter.
- Tap **Clear all** above the results to return to the unfiltered lead list.
