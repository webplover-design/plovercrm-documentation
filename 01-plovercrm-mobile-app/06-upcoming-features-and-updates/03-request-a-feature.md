# Request a Feature

Share feedback about workflows or improvements you would like to see in PloverCRM.

Feature requests open the public PloverCRM roadmap in a browser or external page.

## Open the roadmap

1. Open PloverCRM.
2. Tap **Settings**.
3. Scroll to **Help & updates**.
4. Tap **Request a Feature**.
5. Follow the device prompt to open the public roadmap.

## Submit a useful request

Before submitting a request:

1. Search the roadmap for an existing request that describes the same need.
2. Explain the task you are trying to complete.
3. Describe what makes the current workflow difficult.
4. Explain the result you would like PloverCRM to provide.
5. Include a short example without using private customer information.
6. Submit the request using the roadmap controls.

A clear workflow description helps others understand and evaluate the request.

## Protect private information

Do not include any of the following in public feedback:

- Passwords.
- Access tokens.
- Private customer information.
- Unredacted lead details.
- Confidential workspace information.
- Internal URLs or implementation details.

Use general examples instead of real customer records.

> **Warning:** The roadmap is public. Review your request before submitting it and remove confidential information.

## If the roadmap does not open

1. Tap **Request a Feature** again.
2. Follow the device prompt.
3. If the page still does not open, open the roadmap in a browser.
4. Contact PloverCRM support if you cannot access the roadmap.

## Understand feature-request status

Submitting a request does not guarantee that the feature will be built or released. PloverCRM may change the priority, scope, or timing of roadmap items.

For released improvements, see [View What's New](01-view-whats-new.md).
