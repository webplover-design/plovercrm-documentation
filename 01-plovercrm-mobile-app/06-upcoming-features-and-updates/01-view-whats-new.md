# View What's New

Review the latest PloverCRM updates, improvements, and fixes from the mobile app.

## Open What's New

1. Open PloverCRM.
2. Tap **Settings**.
3. Scroll to **Help & updates**.
4. Tap **What's New**.

The What's New panel opens as a sheet over the app. It shows the latest PloverCRM updates and the current app version.

## Review a release entry

A release entry can show:

- Product name.
- App or plugin version.
- Published date.
- Release title.
- Summary.
- Highlighted changes.
- **Read more**, when additional release information is available.

Scroll through the entries to review the available updates.

## Filter release entries

When release entries are available, use the filters at the top of the panel:

- **All** — Show all available release entries.
- **Plugin** — Show PloverCRM plugin entries.
- **Mobile App** — Show PloverCRM Mobile entries.

Each filter can show a count of matching entries. The available counts depend on the release information currently available.

If a filter has no matching entries, PloverCRM shows a message such as **No mobile app changelog entries are available yet.**

## Read more about an update

1. Open a release entry that includes a **Read more** button.
2. Tap **Read more**.
3. Follow the device prompt to open the additional release information.

## Close What's New

Tap the close button in the top-right corner of the panel to return to Settings.

## Troubleshooting

### What's New is still loading

Wait for the release information to load. If loading does not finish, close the panel and open **What's New** again.

### Changelog unavailable

PloverCRM can show **Changelog unavailable** when release information cannot be loaded. Tap **Retry** and try again later.

### No changelog entries are available

PloverCRM can show **No changelog entries are available yet** when no release entries are available. Check again later.

### Read more does not open

Tap **Read more** again. If the link still cannot open, use a browser or contact PloverCRM support.
