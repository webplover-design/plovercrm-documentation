# Upcoming Mobile App Features

Learn where to find information about planned PloverCRM Mobile improvements and how to share feedback about features you would like to see.

PloverCRM does not guarantee a delivery date for a feature shown on a roadmap. Plans, priorities, and availability can change.

## Review the latest mobile updates

Use **What's New** in the mobile app to review features, improvements, and fixes that have already been released:

1. Open PloverCRM.
2. Tap **Settings**.
3. Scroll to **Help & updates**.
4. Tap **What's New**.
5. Review the available release entries.
6. Tap **Read more** when a release includes a link to additional information.
7. Close the panel when you are finished.

The What's New panel can show the current app version, release version, publication date, summary, highlights, and a **Read more** button.

## Filter update entries

When multiple release entries are available, use the filters at the top of the What's New panel to narrow the list. The available filters and entry counts are displayed by PloverCRM and can change over time.

If no entries match the selected filter, PloverCRM shows a message explaining that no updates are available for that filter.

## Review planned features

To review possible future improvements:

1. Open **Settings**.
2. Tap **Request a Feature** under **Help & updates**.
3. Follow the prompt to open the public PloverCRM roadmap.
4. Review planned items and existing feature requests.

Roadmap items are subject to change. A roadmap item is not a promise that the feature will be included in a particular app version or released on a particular date.

## Request or suggest a feature

1. Tap **Request a Feature** in **Settings → Help & updates**.
2. Open the public roadmap when prompted.
3. Search for an existing request before creating a new one.
4. Add a clear description of the workflow or problem you want PloverCRM to improve.
5. Submit the request using the roadmap controls.

Do not include passwords, access tokens, private customer information, or confidential workspace details in public feedback.

For more information, see [Request a Feature](03-request-a-feature.md).

## Check whether a newer app version is available

A planned feature becomes available to you only after it is released in a supported PloverCRM Mobile version. To check for a newer version:

1. Open **Settings**.
2. Tap **Check for Updates**.
3. Follow the device instructions when an update is available.

On Android, PloverCRM can start the in-app update flow. On Apple devices, PloverCRM can show an update alert with **Update** and **Cancel**. If no update is available, PloverCRM can show **You're using the latest version of PloverCRM.**

See [Check for Mobile App Updates](02-check-for-mobile-app-updates.md) for the complete update workflow.

## Understand update availability

- **What's New** describes updates that have already been published.
- The public roadmap describes possible future work.
- **Check for Updates** checks whether a newer version is available for your device.
- Some features can be released gradually or depend on your workspace, role, device, or app version.
- An update may require you to refresh workspace data before new behavior appears in the app.

## Troubleshooting

### A planned feature is not visible in the app

Confirm that you are using the latest supported version of PloverCRM Mobile. Then check whether the feature requires a permission, workspace setting, or additional setup.

### The roadmap does not open

Tap **Request a Feature** again and follow the device prompt. If the page still does not open, use a browser or contact PloverCRM support.

### What's New has no entries

PloverCRM can show **No changelog entries are available yet** when release information is not available. Try again later.

### The update check does not complete

Review [Check for Mobile App Updates](02-check-for-mobile-app-updates.md), confirm that your device can open the app store or in-app update flow, and try again later.
